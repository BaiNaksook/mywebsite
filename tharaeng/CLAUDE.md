# ท่าแร้งช่วยกัน — บันทึกสำหรับ Claude

อ่านไฟล์นี้ก่อนทำงานทุกครั้ง เป็นความจำของโปรเจกต์จากการคุยกับเจ้าของงานครั้งก่อน ๆ

## เจ้าของงานและวิธีคุย
- เจ้าของเป็นนักเรียน อยู่ **หมู่ 4 ตำบลท่าแร้ง** อ.บ้านแหลม จ.เพชรบุรี
- **คุยภาษาไทยเสมอ** อธิบายสั้น เข้าใจง่าย ไม่ใช้ศัพท์เทคนิคโดยไม่จำเป็น
- ชอบให้ลงมือทำเลย ("ต่อเลย") แต่เรื่องที่ขัดกับสิ่งที่เคยกำหนดไว้ ให้ถามก่อน
- ห้ามขอรหัส/คีย์/ไฟล์ service account ในแชต

## สิ่งที่เว็บนี้คือ
เว็บแผนที่ให้คนในตำบลท่าแร้งแจ้งปัญหา (น้ำท่วมขัง ขยะ ถนนชำรุด ไฟส่องสว่าง อื่น ๆ) และให้จิตอาสารับงาน แก้ไข บันทึกผล
เป็น **โครงงานของนักเรียน** — ห้ามใช้ตรา อบต. หรือทำให้เข้าใจว่า อบต. เป็นผู้ดำเนินการ/ได้รับเรื่องอัตโนมัติ
มีปุ่ม "ติดตามข่าวสารจาก อบต.ท่าแร้ง" ลิงก์ https://www.facebook.com/tambontaraeng

## การตัดสินใจที่เจ้าของเลือกแล้ว (อย่าเปลี่ยนเองโดยไม่ถาม)
- **ไม่ต้องล็อกอิน** — แค่ใส่ชื่อ (ใช้ Firebase Anonymous Auth เบื้องหลัง) Google ใช้เฉพาะผู้ดูแล
- **ใช้ Firebase แพ็กเกจฟรี (Spark) เท่านั้น** — เจ้าของไม่ใช้/ผูกบัตรไม่ได้ ห้ามใช้ Cloud Storage หรือ Cloud Functions
  รูปเก็บเป็น JPEG ย่อแล้ว (≤450 KB) ในคอลเลกชัน `photos` ของ Firestore
- **คำและสีสถานะตามที่กำหนดตอนแรก:** รอความช่วยเหลือ (เหลือง) / กำลังดำเนินการ (น้ำเงิน) / แก้ไขแล้ว (เขียว), ปุ่ม "รับช่วยเหลือ"
  (มีข้อเสนอให้เปลี่ยนเป็น "อาสาช่วย" และสีครามสำหรับคนตาบอดสี — ยังไม่ได้เปลี่ยน รอเจ้าของตัดสินใจ)
- แผนที่แสดง **เฉพาะตำบลท่าแร้ง** (มาสก์นอกเขต + เส้นประ) และมีป้ายชื่อสถานที่
- โทนภาพ: ครีม/ขาว/เขียวอ่อน/เหลืองนุ่ม, minimal, อ่านง่ายสำหรับผู้สูงอายุ, **ห้ามดูเป็น "AI slop"**
  (ไม่มี gradient ฉูดฉาด, glassmorphism, emoji เป็นไอคอน, การ์ดซ้อนการ์ด, ข้อความขายของ) — ดู docs/research/ui-04-anti-slop.md

## ข้อมูลพื้นที่ (ยืนยันแล้ว)
- ตำบลท่าแร้ง รหัส **760709** (ไม่ใช่ท่าแร้งออก 760710 และไม่ใช่แขวงท่าแร้ง กทม.) รหัสไปรษณีย์ 76110
- 7 หมู่บ้าน: หมู่ 1 บ้านดอนเทพศักดิ์, หมู่ 2 บ้านคลองแหลม (?), หมู่ 3 บ้านคลองมอญ,
  **หมู่ 4 และหมู่ 5 ชาวบ้านเรียกว่า "ท่าแร้ง"** (เจ้าของยืนยันเอง), หมู่ 6 บ้านวัดกุฏิ (บางแหล่งว่า บ้านกุ่มนอก), หมู่ 7 บ้านในพัฒนา (ที่ตั้ง อบต.)
- ชุมชนพหุวัฒนธรรม มุสลิมราว 60% — ใช้ตัวอย่าง/ภาษาที่เป็นกลาง (เช่น "หน้ามัสยิด" ไม่ใช่แค่ "หน้าวัด")
- อบต.ท่าแร้ง โทร 032-782097 · เบอร์ฉุกเฉิน 1669 / 199 / 191 / 1129 / 1784
- เส้นขอบเขต: `src/data/tha-raeng-boundary.json` (OCHA COD-AB / กรมแผนที่ทหาร, CC BY-IGO — แบบย่อ ไม่ใช่แนวเขตตามกฎหมาย)
- ป้ายสถานที่: `src/data/places.ts` (พิกัดจาก OSM / Overture) — ยังขาดพิกัด: โรงเรียนบ้านท่าแร้ง (สหราษฎร์) หมู่ 4, มัสยิดกลาง (ยามิอุ้ลอิสลาม) หมู่ 4
- รายละเอียดและแหล่งที่มาทั้งหมด: `docs/research/01-*.md` ถึง `12-*.md`

## Firebase
- โปรเจกต์: **tha-raeng-chuai-kan** · เว็บ: https://tha-raeng-chuai-kan.web.app
- config อยู่ใน `.env` (เป็นค่าสาธารณะ commit ได้)
- ต้องเปิดใน Console: Authentication → Anonymous + Google, และสร้าง Firestore (asia-southeast1)
- Deploy: `npm run deploy` (ต้อง `npx firebase login` ในเครื่องก่อน) หรือ GitHub Actions `.github/workflows/deploy-tharaeng.yml` (ต้องมี secret `FIREBASE_SERVICE_ACCOUNT`)

## โค้ด
- React 19 + Vite + TypeScript, Leaflet + OSM tiles, Firebase JS SDK v12
- สำคัญ: `src/lib/reports.ts` (อ่าน/เขียน + transaction), `firestore.rules` (สิทธิ์ทุกการกระทำ + ประวัติแบบเพิ่มได้อย่างเดียว)
- ถ้าเปลี่ยนกรอบพื้นที่ ต้องแก้ทั้ง `ALLOWED_BOUNDS` (src/config.ts) และ `inArea()` (firestore.rules)

## ก่อนส่งงานทุกครั้ง
```
npm run build
npm run test:rules   # ต้องผ่านทั้งหมด (ใช้ Firebase Emulator — ต้องมี Java 21)
npm run test:e2e     # เส้นทางหลัก: แจ้ง → หมุดขึ้นเรียลไทม์ → รับช่วย → แก้แล้ว → สถิติเปลี่ยน → เปิดใหม่
```
ถ้า test:e2e หา Chromium ไม่เจอ ให้ `npx playwright install chromium` หรือตั้ง `CHROMIUM_PATH`
